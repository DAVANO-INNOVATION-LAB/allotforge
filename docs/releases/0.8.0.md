# AllotForge 0.8.0 development prerelease

## Added

- Workload inspection timelines for the current rolling 15-minute observation. They expose the same accepted minute values behind CPU, memory and custom-adapter GPU summaries, without another query or a history store.
- Explicit missing-minute gaps, measured-zero distinction, per-metric units and accessible interval values. Every non-observed metric has a null timeline; partial evidence cannot bypass the existing attribution, freshness and coverage gates.
- Source-mode and timestamp-provenance checks before chart rendering. cAdvisor remains CPU/RAM-only; it never supplies a GPU chart or processor-suitability verdict.

## Interpretation

Timeline labels are derived rolling interval bounds, not actual sample timestamps. CPU and memory aggregate required container minute means; custom GPU values are request-count-weighted means. Missing intervals are not interpolated or zero-filled. A GPU mean can conceal a busy device. The existing conservative assessment and its separately aligned comparison basis are unchanged.

These plots are not whole-job profiles, instantaneous peaks, exact time-weighted CPU integration, performance comparisons or cost estimates. Refresh replaces the current window. No workload is moved, submitted, resized or migrated. No additional network permission, background polling, durable telemetry history or collector is added.

## Verification limits

Tests use synthetic observations and DOM/API checks. Static previews are labelled synthetic and not native browser QA. No live cAdvisor installation, real GPU, target cluster or production workload was validated. Existing source assertions, operator authentication boundaries, compatibility names and pending license selection remain in effect.
