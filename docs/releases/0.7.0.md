# AllotForge 0.7.0 development prerelease

## Added

- A separately selected cAdvisor CPU/RAM source for the Workload advisor. It matches exact current Pod/container cgroup identities, derives CPU interval-average rates from bounded raw counters and preserves memory working-set samples. No new collector, runtime socket, Kubernetes role or host access is added.
- Explicit source-timestamp preservation prerequisites. The source stays disabled without the advisor opt-in and an administrator assertion that original cAdvisor timestamps survive the ingestion pipeline. The interface distinguishes that assertion from independent verification and shows the real source metrics and aggregation limits.
- An offline GPU smoke-bundle verifier. It checks exported Job/Pod identities, the fixed program, requested image/resources, raw CUDA timing output and an operator capture receipt. Bounded inputs, ambiguous/restarted attempts, malformed values and conflicting evidence fail closed. Reports use exclusive creation to avoid overwriting captures.
- Manual capture instructions, primary-source telemetry research and a future hardware attribution acceptance matrix.

## Safeguards

cAdvisor mode supplies no GPU evidence or CPU/GPU recommendation. Wrong-mode readers, ambiguous current runtime identities, counter resets, stale/cached samples, unsupported paths and duplicate/per-CPU streams cannot become valid aggregate observations. CPU and memory failures remain independent. The interface withholds measurements when source or per-metric timestamp assertions are absent or inconsistent.

The custom-adapter mode remains separate and unchanged in purpose. Its optional CPU-comparison suggestions are still experiments, not placement decisions or proof of faster/cheaper execution.

## Requirements and limits

Verify the actual cAdvisor producer, preserved timestamps, cadence and trusted node/cluster/workload labels before enabling this source. Defaults differ between monitoring distributions. The consumer cannot independently inspect or attest the entire ingestion pipeline. A 30-second cadence normally cannot produce the required 41 CPU interval observations in 15 minutes. CPU summaries are equal-weight minute summaries of interval rates, not exact continuous integration. Working set is not RSS or proof that memory is unreclaimable.

Offline smoke consistency does not authenticate exports or prove GPU execution. Image-index/runtime digest mapping, whole-GPU exclusivity, live performance and savings remain unverified. No source is automatically promoted into a live benchmark campaign.

No live cAdvisor installation, real GPU, target cluster or native browser interaction was validated. Tests use synthetic fixtures, API/transport doubles and DOM checks. Static previews are labelled accordingly. Exact-commit disposable Kubernetes regression checks remain separate from GPU execution evidence. No production resources or paid workloads were provisioned. Existing `davano` compatibility and pending license selection remain in effect.
