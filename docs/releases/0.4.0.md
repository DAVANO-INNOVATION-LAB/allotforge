# AllotForge 0.4.0 development prerelease

## Added

- Separately enabled, GET-only pending-workload summary observations for up to ten explicit namespace/LocalQueue targets.
- A dedicated UI section for API-reported zero-based queue positions, source/time, bounded counts, partial windows and unavailable evidence. No ETA or promised admission order.
- Strict separation between identity-unverified summary entries and actual Workload admission records. Stock Kueue omits Workload UID, so names and owner UIDs are never substituted for stable identity.
- Bounded responses, call count and between-request time budget; malformed/conflicting responses fail closed. Optional visibility errors preserve existing queue conditions.
- An unbound, unapplied least-privilege Role/discovery-ClusterRole review template. Nothing installs Kueue or grants permissions automatically.

## Verification and limits

Python, UI and independent contract-review checks cover synthetic upstream-style responses, UID omission, malformed/duplicate ranks, bounds, optional failures, scope and redaction. Existing exact-commit release gates include disposable Kubernetes admission tests and deployment validation. This feature was not exercised against a live Kueue service, production queue, or real GPU hardware. Retrieval time is not proof of source-cache freshness, and a bounded window is not total backlog.

See docs/observability.md for configuration and the pinned upstream v0.20.5 contract. See RELEASE-VERIFICATION.md and the exact commit's GitHub Actions result for verification scope. Existing davano module/configuration compatibility is retained. License selection remains pending.
